\begin{block}{Empirical cdf}
The empirical cdf of a set of values $X_1,\dots,X_n \in \mathbb{R}$ is given by
\[
\hat F_n(x) = \frac{1}{n}\sum_{i=1}^n\mathbf{1}(X_i \leq x) \quad \text{ for all } x \in \mathbb{R}.
\]
\end{block}
